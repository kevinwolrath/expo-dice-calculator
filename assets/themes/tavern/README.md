# DiceForge Tavern Theme Asset Pack

Day-only theme pack. Night view is not customised by this pack.

Files:
- theme.json – colour tokens and asset filenames
- assets.ts – Metro `require()` map for bundled images
- background.jpg – full-screen portrait background (day)
- banner.jpg – Jobs screen/header banner
- icon_*.png – transparent fantasy field icons
- preview_footer_parchment.png / preview_icon_*.png – dice preview footer

A pack is loaded when this folder shape exists under `assets/themes/<id>/` (`theme.json` + `assets.ts`). There is no central list of pack names.
